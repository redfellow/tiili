## Approach

- `src/layout.ts`: `gridFor(n, mode = "grid", size?: { cols: number; rows: number; prev?: number })` where size is the pane area in character cells and `prev` the current column count. Only `grid` uses size. `chooseGridColumns(n, size)`: score each c in 1..n by `|ln((W/c)/(H/r) / (80/24))| + 0.15*(r*c-n)`, discard c whose pane width < 60 columns unless all are; pick lowest. Hysteresis: if `prev` is given and differs from the pick, keep `prev` unless the area's aspect, measured in 80×24 pane units, lies outside [0.87, 1.15] of the boundary between the two scores (implementation: keep prev when its score is within 2·ln(1.15) of the best; near the boundary the two scores move apart by 2·ln(f) when the aspect is a factor f past it, so this flips at 15% past).
- `src/layout/model.ts`: `LayoutState` gets optional `area?: {cols, rows}`; `reflow` passes it and `prev.cols` to `gridFor`. New `setArea(state, area)` re-flows; tracks keep sizes when counts are unchanged (existing rule).
- `src/tab.ts`/`src/panes.ts`: measure the tab area in cells (existing cell metrics used near `MIN_COLS * cell.width`), set the area before add/remove/restore, and on a ResizeObserver debounced 250 ms call `relayout(setArea(...))` only when the grid would change.
- `src/session.ts`: `tabPlan` validates sizes against saved `layout.cols`/`layout.rows` when they are positive integers with cols*rows ≥ n and the mode is grid; otherwise `gridFor(n, mode)`. The plan returns `cols`/`rows` so the tab restores that shape until the first settled measure.
- `src/settingsDialog.ts` and `src/tilingPicture.ts`: `tilingPicture("grid", window)` gives Grid's choice for the window's size in cells and a box of that aspect, which `tilingIcon` draws. The Settings window is a window of its own, so `settings_open` in `src-tauri/src/settings.rs` adds the opening tiili window's inner size to its URL (`&width=&height=`, logical px); the dialogue reads it there, or uses `window.innerWidth/innerHeight` when the URL has none, and divides by the cell size measured from the font (a cell half as wide as it is tall when that can't be measured).

Why: the scoring lives in the pure `gridFor`, so it is unit-tested without a window; the model keeps its existing size-keeping rule.

## Approach
- **Signals (frontend, `src/attention.ts`)**: pure functions `parseOsc9`, `parseOsc777`, `parseOsc99`, `sanitizeMessage` (strip control chars, drop >4096 bytes), and a per-pane `AttentionGate` that merges BEL+OSC 9 within 100 ms (message kept) and rate-limits to one fire per 2 s. `terminal.ts` wires `term.onBell` and `term.parser.registerOscHandler(9|777|99)`; xterm already knows a BEL that ends an OSC isn't a bell. Heynote panes never register.
- **Focus rule**: the frontend drops a signal when its pane is focused and its window is focused (`document.hasFocus()`), and clears on pane focus while the window is focused, on window focus for the focused pane, and on exit/close.
- **Registry (Rust, `src-tauri/src/attention.rs`)**: `Attention` state `session → {seq, message, bell}` with commands `attention_mark`, `attention_clear`, `attention_next` (oldest seq → owner label from `Sessions::owner`, focuses that window and emits `attention-focus` with the session), and an `attention-changed` event to all windows carrying the list of marked sessions. Keyed by session, so a moved pane keeps its mark with no change to `MovePayload`; `Sessions::remove` also clears. Pure logic (ordering, counts) is unit-tested.
- **OS level (Rust)**: on every change and on app focus change, if no tiili window is focused: macOS `set_badge_count` + `request_user_attention(Informational|Critical)` once per new mark; Windows per-window `set_overlay_icon` (brick PNG) + `request_user_attention`; Linux `set_badge_count` + `request_user_attention`. Bounce setting Never skips it. Cleared when any tiili window gains focus (badge kept in sync with count).
- **Notifications**: `tauri-plugin-notification`; Rust batches marks with a message (and bells if "Messages and bells") in a 2 s window: one → title `<place> · <command>` (sent by the frontend with the mark), body message; more → "N panes need you". One per session until it clears. Permission requested at first send. Click: start with a spike task; where the click reaches the app, focus that pane via `attention-focus`, else just show the app.
- **Settings**: three fields in `settings.ts` / `settings.rs` with fallback defaults; Attention section in `settingsDialog.ts`; Remote shells snippet gets a fixed height with inner scroll if needed for 720×640.
- **Shortcut**: `attentionShortcut` in `keymap.ts` (Cmd+J / Ctrl+Shift+J).

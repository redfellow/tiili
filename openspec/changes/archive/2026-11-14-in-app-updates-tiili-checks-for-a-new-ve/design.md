# Design

- **Rust**: register `tauri_plugin_updater::Builder::new().build()` and `tauri_plugin_process::init()` in `src-tauri/src/lib.rs`; add capabilities `updater:default` and `process:allow-restart`. A command `update_install_kind` returns `"deb"` on Linux when `APPIMAGE` is unset, else `"bundle"` (pure helper `install_kind(os, appimage_set)` unit-tested).
- **Config**: `tauri.conf.json` gets `bundle.createUpdaterArtifacts: true` and `plugins.updater` with the endpoint and pubkey `dW50cnVzdGVkIGNvbW1lbnQ6IG1pbmlzaWduIHB1YmxpYyBrZXk6IDc3RTYwRDNFQjg1Mjk0OUUKUldTZWxGSzRQZzNtZDd1MVk2UHVrNTArTkd6c2lsZGZQK2lNMmkxcndZUTl5TitsbEhXWGx5cjUK`. Local `npm run bundle` without the key: `scripts/bundle.mjs` passes `--config {"bundle":{"createUpdaterArtifacts":false}}` when `TAURI_SIGNING_PRIVATE_KEY` is unset, so unsigned local and CI builds still succeed.
- **Frontend**: `src/updates.ts` holds pure logic — `shouldAutoCheck(now, lastCheck, enabled)` (24 h), `isSkipped(version, skipped)` — and the flow (`check()` from the plugin, `downloadAndInstall`, `relaunch()`). `src/updateDialog.ts` renders the in-app dialog in the main window with notes, progress and errors. Settings gain `updates: { autoCheck: boolean }` normalised with default `true`.
- **Release**: `scripts/updater-manifest.mjs` builds `latest.json` from the tag, notes and the `.sig` files found per platform (darwin-aarch64 → `.app.tar.gz`, windows-x86_64 → `-setup.exe`, linux-x86_64 → `.AppImage`); urls use `https://github.com/redfellow/tiili/releases/download/<tag>/<file>`. Bundle jobs upload the updater bundles and `.sig`s; a `manifest` job after them downloads the `.sig` assets, runs the script and uploads `latest.json`. When the secret is missing the bundle job skips updater artifacts and the manifest job warns and exits 0.
- The workflow is a human-only path, so its new text is a triage task.

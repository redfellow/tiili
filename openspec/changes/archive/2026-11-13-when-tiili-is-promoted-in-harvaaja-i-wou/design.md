## Approach
A Node script in the style of `scripts/bundle.mjs`. The steps are kept as pure helpers, exported for a unit test: the build arguments, the path of the built .app, the check for whether a `persistent-apps` dump already holds `app.tiili` or `/Applications/tiili.app`, and the Dock entry XML. A thin `main` runs them in order: `npx tauri build --bundles app`, quit tiili, `ditto` the built app over `/Applications/tiili.app` after removing the old one, then `defaults write com.apple.dock persistent-apps -array-add <entry>` and `killall Dock` only if tiili isn't pinned yet. Building for the host architecture, with no `--target`, keeps it fast. The built app lands in `src-tauri/target/release/bundle/macos/tiili.app`.

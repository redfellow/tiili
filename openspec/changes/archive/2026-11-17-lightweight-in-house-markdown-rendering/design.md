## Approach
New `src/markdown.ts`: `parseMarkdown(body): Block[]` (pure; blocks = heading | paragraph | list(ordered) of inline runs; inline = text | strong | em | code | link{href,text}). It first drops `<details>…</details>` and the `**Full changelog` line, strips HTML tags the way `plainNotes` does, then parses line by line. A link keeps its href only when it starts with `https://`; otherwise it becomes text. `renderMarkdown(blocks)` in `src/updateDialog.ts` (or markdown.ts) builds elements with `textContent` only; link clicks call `openUrl` like See all changes. The `pre.update-notes` becomes a `div.update-notes.update-markdown` styled with the normal font and `white-space: normal`. Pure parser = unit-testable without a DOM; no dependency keeps footprint small.

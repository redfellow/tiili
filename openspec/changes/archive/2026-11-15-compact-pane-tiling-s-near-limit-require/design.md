## Approach

Rewrite each of the five requirements as one short statement. The precise detail (formulas, keys, timings, menu items, edge cases) moves into scenarios, so each requirement's text stays well under 500 characters and has room to change. Existing scenarios are kept word for word, apart from Opening/Closing a pane animates, which gain the timings that used to be in the requirement text. Splitting requirements was rejected: it would add names, and the requirement statements are short enough without it.

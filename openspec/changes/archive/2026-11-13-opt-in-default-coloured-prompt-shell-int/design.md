## Approach
- **Frontend**: `PROMPT_IDS = ["off","classic","minimal","tiili"]` in `src/settings.ts`, clamped on load like `theme`. `src/promptStyles.ts` holds each style's label, group and preview segments as `{ text, ansi: 0..15 | "fg" }`; the dialogue renders segments with `var(--ansi-N)` on `--term-bg`, so previews follow the theme with no extra code. `pickList` row in `settingsDialog.ts` mirrors `themeList`.
- **Spawn plumbing**: `Backend.spawn` gains a `prompt` argument; `backend-tauri.ts` passes it to `pty_spawn`, the dev WebSocket bridge forwards it too. `SessionRegistry::spawn_tracked` → `PtySession::spawn_in(cwd, prompt, …)`. The pane reads the current saved/previewed setting when it opens.
- **Rust `shell_integration.rs`**: pure `fn plan(shell_path, prompt, dir) -> ShellPlan { program, args, env }`, unit-tested table-driven. Off or an unknown shell → default program, no args. zsh: `ZDOTDIR=<dir>/zsh`, `TIILI_USER_ZDOTDIR=<old ZDOTDIR or $HOME>`, `TIILI_PROMPT=<id>`; the tiili `.zshenv/.zprofile/.zshrc/.zlogin` each source the user's counterpart with ZDOTDIR restored, and `.zshrc` sets PROMPT only if still the default. bash: `bash --rcfile <dir>/bash/tiili.bash -i` (login semantics kept by sourcing the user's profile files in order inside it). PowerShell: `-NoExit -Command ". '<dir>/pwsh/tiili.ps1'"` wrapping `prompt` only when unmodified. Scripts are `include_str!` and written to the cache dir; any write failure falls back to the plain spawn.
- `cmd.env("COLORTERM","truecolor")`, `TERM_PROGRAM`, `TERM_PROGRAM_VERSION` (from `env!("CARGO_PKG_VERSION")`) always.
- Prompts emit `\e[3Nm` codes only, so the theme's ANSI slots colour them.

# docs-sync Specification

## Purpose
Keep tiili's README, website and other prose that repeats code in step with that code, by generating the shortcut tables and checking the other copies in the unit tests.

## Requirements

### Requirement: Shortcut tables list every shortcut
The README and the site SHALL list every keyboard shortcut tiili handles, grouped, generated by `npm run docs` from one list kept beside the keymap; the unit tests SHALL fail when the list and keymap disagree or the committed tables are stale.

#### Scenario: A keymap chord without a list entry
- **WHEN** a keymap function accepts a chord that no list entry names
- **THEN** the unit tests fail

#### Scenario: Stale tables
- **WHEN** the committed README or site table differs from what `npm run docs` writes
- **THEN** the unit tests fail with a message telling to run `npm run docs`

### Requirement: Other doc copies are checked against the code
The unit tests SHALL check that macOS menu accelerators match keymap actions (Cmd+Q excepted), theme families are named in README and site, `tiili` example flags exist in its usage, every bundled font is licensed, the brand tint table matches `tiili.css`, and `npm run` mentions and relative doc links exist.

#### Scenario: A documented flag the CLI lacks
- **WHEN** a `tiili open` example in a skill or spec uses a flag not in the CLI usage text
- **THEN** the unit tests fail naming the flag

Every terminal a brick, the window a wall.

tiili is a terminal that tiles itself. Open a shell and it fills the window; open more and they settle into a grid on their own. Every pane is a real shell, tinted by the git repository it sits in, so a window of servers, logs, editors and a coding agent or ten stays readable at a glance.

Features

Built for a window full of shells

Each brick below is a pane. Point at one to give it focus: it gets the brick line and the solid cursor, the rest dim a little, just as in the app.

tiling zsh

Auto-tiling

Fullscreen, side by side, 2×2, 3×3 and on. Drag dividers to resize, drag a pane's top edge to swap, reset to an even grid with one key.

repos git

Panes that tell you where you are

Panes in the same git repository share a tint and a name chip that follows cd. Each title shows what is running, such as bash or top.

api web docs infra mobile
clipboard pbcopy

Copy and paste that work

⌘C ⌘V on macOS. Ctrl+Shift+C V on Windows and Linux, so Ctrl+C still interrupts. Right-click works too.

themes settings

Themes and fonts

tiili Light and Dark, Savi, Muratti, Koski, Laasti, Solarized, Gruvbox, Nord and Dracula, previewed as you pick. Any installed font, with ligatures, weights, line height and spacing.

notes heynote

Heynote scratchpad

The note button next to + opens Heynote in a pane of its own, with notes saved as plain files.

native tauri

Small and native

Tauri 2 and xterm.js, around 10 MB, no Electron. It reopens where you left the window, and its icon follows light and dark mode.

private offline

Yours alone

No accounts, no sync, no telemetry. Every pane is a real TTY running your own shell, with your own config.

mit open source

Free and open

MIT licensed and on GitHub. Read the code, file an issue, or build it yourself.

Download · latest release

Get tiili

Installers come from the latest GitHub release. The builds are not signed yet, so the first launch takes one extra step.

macOS Your system

Universal: Apple Silicon and Intel.

First launch

Drag tiili to Applications and open it, then click Open Anyway in System Settings → Privacy & Security. If macOS says the app is damaged:

xattr -dr com.apple.quarantine /Applications/tiili.app

Windows Your system

64-bit installer.

First launch

When SmartScreen says "Windows protected your PC", click More info → Run anyway.

The name chip follows cd once your shell reports its folder: see Windows: let the chip follow cd.

Linux Your system

.deb for Debian and Ubuntu, .AppImage for the rest.

Install 
sudo apt install ./tiili_*_amd64.deb
# or
chmod +x tiili_*_amd64.AppImage && ./tiili_*_amd64.AppImage

Rather build it yourself? You need Node.js and Rust: see Building from source.

How it's made

Planned, built and reviewed by coding agents

tiili is built on härvääjä, a board that runs each idea as a card through an OpenSpec change: plan, build, checks, review, merge. The specs live in the repository next to the code.

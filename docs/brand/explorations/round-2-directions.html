Colour roles for the app

  • tiili #A4472B is the one accent: cursor, focus, primary button. On dark grounds it is a mark colour, not a text colour; text uses savi #C9764F instead.
  • klinkkeri, savi, rauta, ikkuna, muratti and koivu are the project tints, assigned per git repo.
  • koski #182023 is the default terminal background; laasti and kalkki are the light theme's ground.
